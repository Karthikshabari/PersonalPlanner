    Why I built this

    Less pretending.
    Here's why I ended up building this

    I made Personal Planner because I kept giving myself the same unrealistic estimates. The next day would start, and I'd plan as though yesterday hadn't happened.

    I wanted a planner where looking back is as natural as planning ahead. It started as something I needed for myself, and it's now something others can try too.

    I use it every day, on my laptop and on my tablet, and when something about it bugs me I fix it. I test as much as I can before each release, and I'm slow to add things. I'd rather it did a few things properly.

    Installing it, step by step

    The Windows and macOS builds aren't code-signed yet, so those systems will ask you to confirm. Unsigned only means the system can't see who published the file. The source is public, so you can read exactly what you're installing.

    1. Download the .zip from the Windows card above.
    2. Extract the whole zip (right-click, then Extract All). Keep personal_planner.exe, the .dll files and the data folder together.
    3. Run personal_planner.exe.
    4. If Windows says “Windows protected your PC”, that's the unsigned warning. If you got the file from the Releases page, choose More info, then Run anyway.
    Check the download (optional)

    This release includes a SHA256SUMS.txt. In PowerShell, in the folder you downloaded to:

    Get-FileHash .\*windows*.zip -Algorithm SHA256

    The long value it prints should match the Windows line in SHA256SUMS.txt.

    1. Download the .zip from the macOS card above and double-click it to unzip.
    2. Move Personal Planner.app to your Applications folder.
    3. Open it. If macOS blocks it, open System Settings → Privacy & Security and choose Open Anyway.
    4. Still blocked? Once you're sure the file came from the Releases page, run this in Terminal:
      xattr -dr com.apple.quarantine "/Applications/Personal Planner.app"

    I don't own a Mac, so the macOS build is tested by GitHub Actions and not on a real one. If something is off, please tell me.

    Check the download (optional)
    shasum -a 256 *macos*.zip

    Compare it with the macOS line in SHA256SUMS.txt from the same release.

    1. Download the .tar.gz from the Linux card above.
    2. Extract it:
      tar -xzf *linux*.tar.gz
    3. Open the extracted folder and run the app inside it.
    4. Reminders and timer notifications work on Linux.
    Check the download (optional)

    With SHA256SUMS.txt in the same folder:

    sha256sum -c SHA256SUMS.txt --ignore-missing

    It should print OK next to the file you downloaded.

    1. Download the .apk on your phone, or copy it over from a computer. You can scan the QR code above to open the release page.
    2. Open the file. Your phone may ask you to allow installs from your browser or file manager. That's normal for an app that isn't on Google Play.
    3. Open Personal Planner. Reminders and timer notifications work on Android.
    4. To update later, install the newer APK over the old one.
    Before you download

    Things you might
    be wondering.

    A few of these have caveats. I'd rather you hear them from me than find out later.

    Why did you make this?
    I'm Karthik, a developer. I made it because I kept making the same bad estimates, and I use it every day myself.
    Do I need an account?
    No. Everything works offline, with your data in a database on your own device. An account only comes into it if you turn on sync.
    Where is my data stored?
    On your device. Sync is optional, and it uses a Supabase project that you set up yourself.
    Can I back up or move my data?
    Yes. Backup and restore are built into the app.
    Is there an iPhone or iPad version?
    Not yet. Right now it's Windows, macOS, Linux and Android. It isn't on Google Play either, so on Android you install the APK from GitHub.
    Why do Windows and macOS show a warning?
    Those builds aren't code-signed yet, so the system warns you about an unknown publisher. The install steps get you past it, and the source is public if you'd like to read it first.
    How do I report a bug or suggest something?
    Open an issue on GitHub. That's the quickest way to reach me.
